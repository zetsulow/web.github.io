La Structure du Web & PHP

Comprendre le fonctionnement du web, l'architecture Client-Serveur et l'intégration du PHP

1. Le Modèle Client-Serveur

Le web repose entièrement sur un modèle d'échange entre deux entités distinctes : le Client et le Serveur via le protocole HTTP/HTTPS.

Les deux acteurs principaux

  • Le Client (Navigateur Web) : Envoie des requêtes (ex: Chrome, Firefox) et interprète les langages client-side pour afficher la page (HTML, CSS, JavaScript).
  • Le Serveur Web : Reçoit les requêtes, traite la logique métier sur le serveur (via PHP, Python, Node.js) et renvoie un résultat lisible par le navigateur.

2. Sites Statiques vs Sites Dynamiques

Selon la manière dont le contenu est généré, on distingue deux types de technologies web.

Les différences clés

  • Web Statique (HTML/CSS) : Le serveur renvoie directement le fichier tel qu'il est stocké. Tous les utilisateurs voient exactement le même contenu.
  • Web Dynamique (PHP/SQL) : Le serveur exécute du code avant d'envoyer la page. Le contenu peut changer selon l'utilisateur, l'heure ou les données d'une base de données.

3. Intégrer du PHP dans du HTML

PHP (Hypertext Preprocessor) est un langage d'exécution côté serveur. Il s'insère directement dans une structure HTML à l'aide de balises spécifiques <?php ... ?>.

<!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Page Dynamique</title> </head> <body> <h1><?php echo "Bienvenue sur mon site !"; ?></h1> <p>Aujourd'hui nous sommes le : <?php echo date('d/m/Y'); ?></p> </body> </html>
Note : Le fichier doit obligatoirement avoir l'extension .php pour que le serveur exécute le code avant de l'envoyer au navigateur.

4. Les trois langages fondamentaux du web

Une page web moderne est la combinaison de plusieurs technologies complémentaires.

  • HTML (Structure) : Définit le squelette et le contenu de la page (titres, paragraphes, images).
  • CSS (Apparence) : Gère le style visuel, les couleurs, la typographie et la mise en page responsive.
  • JavaScript (Interactivité) : Exécuté par le navigateur pour rendre la page dynamique côté client sans recharger la page.

À retenir

  • Le Client demande la page, le Serveur la fabrique et la renvoie.
  • Le code PHP n'est jamais visible par l'utilisateur : il est traduit en HTML pur par le serveur.
  • Le HTML structure, le CSS décore, le JS anime, et le PHP traite les données.
  • Pour exécuter du PHP en local, il faut un serveur web comme XAMPP, WampServer ou Docker.
