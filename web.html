La Structure du Web & PHP

Comprendre le fonctionnement du web, l'architecture Client-Serveur et l'intégration du PHP

1. Le Modèle Client-Serveur

Le web repose entièrement sur un modèle d'échange entre deux entités distinctes : le Client et le Serveur via le protocole HTTP/HTTPS.

Les deux acteurs principaux

  • Le Client (Navigateur Web) : Envoie des requêtes (ex: Chrome, Firefox) et interprète les langages client-side pour afficher la page (HTML, CSS, JavaScript).
  • Le Serveur Web : Reçoit les requêtes, traite la logique métier sur le serveur (via PHP, Python, Node
